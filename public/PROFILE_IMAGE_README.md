# Profile Image Setup

To display your profile image on the website, place your profile photograph as `profile.jpg` in this public folder.

The image will be automatically displayed in:
- Hero section (right side with frame and glow effect)
- Professional profile frame with premium styling

## Recommended Image Specifications:
- Format: JPG or PNG
- Size: 400x500px or larger
- Aspect Ratio: Portrait (3:4 or similar)
- Quality: High resolution (300+ DPI recommended)

## How to Add:
1. Save your profile photo as `profile.jpg`
2. Place it in this `public/` folder
3. The website will automatically display it with professional styling

The image will appear with:
- Rounded professional frame
- Subtle blue glow effect
- Floating info cards showing CGPA and graduation year
- Responsive sizing on all devices
