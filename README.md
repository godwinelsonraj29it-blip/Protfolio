# Godwin Elsonraj A - Personal Portfolio

A modern, premium, clean and highly attractive personal portfolio website built with React, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Modern Design**: Premium, clean aesthetic inspired by technology companies and SaaS websites
- **Responsive**: Fully responsive design that works perfectly on desktop, tablet, and mobile
- **Smooth Animations**: Subtle animations using Framer Motion for enhanced user experience
- **Performance**: Built with Vite for lightning-fast development and production builds
- **Accessibility**: Semantic HTML, ARIA labels, and keyboard-friendly navigation
- **SEO Optimized**: Meta tags and Open Graph support for better search engine visibility

## 📋 Sections

- **Navbar**: Sticky navigation with mobile menu
- **Hero**: Impressive introduction with profile image and floating info cards
- **About**: Professional introduction with statistics
- **Education**: Timeline-style education display
- **Skills**: Technical skills in a grid layout
- **Certification**: Infosys Java certification display
- **Languages**: Language proficiency cards
- **Career Goal**: Career aspirations and long-term goals
- **Currently Learning**: Skills and technologies being developed
- **Projects**: Empty state for upcoming projects
- **Contact**: Contact form and communication options
- **Footer**: Links, contact info, and copyright

## 🛠️ Tech Stack

- **React** 18.2.0 - UI library
- **Vite** 5.0.0 - Build tool
- **Tailwind CSS** 3.3.5 - Utility-first CSS framework
- **Framer Motion** 10.16.4 - Animation library
- **Lucide React** 0.263.1 - Icon library

## 📦 Installation

1. **Install dependencies:**
```bash
npm install
```

2. **Add your profile image:**
   - Place your profile photo as `public/profile.jpg`
   - The image will be displayed in the Hero section with a professional frame

## 🏃 Running the Project

### Development Mode
```bash
npm run dev
```
The application will open at `http://localhost:5173` automatically.

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
